# ARM Cortex-M0 Interfacing and Assembly Programming

## Overview

This repository contains the laboratory work for **ARM Cortex-M0 Interfacing and Assembly Programming**, covering ARM Assembly Language Programs (ALPs), memory operations, GPIO interfacing, display interfacing, and an RTOS case study.

## Software Used

* **Keil uVision5** — Assembly programming and debugging
* **STM32CubeIDE** — STM32F051-based interfacing experiments

## Experiments

1. **Sum of 10 Numbers**
   Find the sum of 10 numbers stored in memory and store the result in memory.

2. **Largest Number**
   Find the largest number among 10 numbers stored in memory and store the result in memory.

3. **Ascending Order**
   Arrange 10 numbers stored in memory in ascending order and store the result in memory.

4. **Even and Odd Numbers**
   Find even and odd numbers among 10 numbers stored in memory using the `ROR` instruction.

5. **LED Interfacing**
   Interface and blink an LED using an ARM Cortex-M0 and GPIO.

6. **LCD Interfacing**
   Interface an LCD module using GPIO and display a message.

7. **Seven-Segment Display**
   Interface a seven-segment display and display numbers.

8. **Seven-Segment Counter**
   Interface a seven-segment display and implement a counter.

9. **FreeRTOS Case Study**
   Study the fundamentals and working concepts of the FreeRTOS real-time operating system.
